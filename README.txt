DELIVERY MATICO - PROYECTO ANDROID

Este archivo ZIP contiene el proyecto fuente para generar un APK en Android Studio.
No es todavía un APK compilado.

CÓMO GENERAR EL APK:
1. Instala Android Studio en una computadora.
2. Descomprime este ZIP.
3. En Android Studio, elige Open y selecciona la carpeta DeliveryMaticoAndroid.
4. Espera a que termine Gradle Sync. Si lo solicita, instala Android SDK 35.
5. Menú Build > Build Bundle(s) / APK(s) > Build APK(s).
6. El APK de prueba se generará en app/build/outputs/apk/debug/app-debug.apk.
7. Copia ese APK al Motorola y ábrelo para instalarlo. Android puede pedir permiso para instalar apps de esa fuente.

IMPORTANTE:
- Esta app contiene el prototipo HTML actual.
- El catálogo y las tarifas se guardan localmente en el dispositivo.
- WhatsApp abre el chat al enviar un pedido.
- No hay GPS/mapas ni cálculo real de distancia, backend, panel web sincronizado,
  cuentas de clientes/repartidores, pagos ni notificaciones push.
- El proyecto requiere Android Studio/SDK para compilar; no se ha generado ni probado un APK aquí.
